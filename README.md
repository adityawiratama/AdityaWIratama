# Aditya Wiratama Ramadhan

Software Engineer di PT Hayago Robotika Indonesia (AITOMA), berbasis di Indonesia.

Saya membangun aplikasi web dan sistem IoT, dengan fokus pada ekosistem JavaScript dan Laravel. Saya juga berpengalaman mengintegrasikan payment gateway untuk pasar Indonesia (Midtrans dan Duitku).

## Projects

- **[AITOMA CMMS](https://github.com/adityawiratama?tab=repositories&q=cmms)** — Sistem manajemen perawatan aset multi-tenant. Laravel, React, PostgreSQL. *(private)*
- **[Vityuu](https://github.com/adityawiratama?tab=repositories&q=vityuu)** — Web app e-commerce dengan integrasi Midtrans dan Duitku. React, Node.js, Express.
- **[Tandurai](https://github.com/adityawiratama?tab=repositories&q=tandurai)** — Dashboard monitoring IoT untuk budidaya jamur. React, Firebase, ESP32.
- **[CalmSwing](https://github.com/adityawiratama?tab=repositories&q=calmswing)** — Sistem monitoring dan penenang bayi dengan deteksi tangisan. ESP32.
- **[Forest Eye](https://github.com/adityawiratama?tab=repositories&q=forest)** — Aplikasi web pemantauan area hutan. Next.js, Python.
- **[Taman Zakat](https://github.com/adityawiratama?tab=repositories&q=zakat)** — Platform digital zakat, infaq, dan donasi.
- **[SmartRoom](https://github.com/adityawiratama?tab=repositories&q=smartroom)** — Monitoring dan kontrol ruangan berbasis IoT.

Project lainnya ada di [Repositories](https://github.com/adityawiratama?tab=repositories).
