## About

Fokus saya ada di ekosistem **JavaScript** dan **Laravel**. Saya suka mengerjakan sistem yang menyambungkan perangkat fisik dengan aplikasi web, mulai dari sensor ESP32 sampai dashboard real-time, serta sistem bisnis seperti e-commerce dan manajemen aset multi-tenant.

<table>
  <tr>
    <td width="33%" valign="top">

    </td>
    <td width="33%" valign="top">
      <h4>IoT Systems</h4>
      ESP32 dan Firebase untuk monitoring dan kontrol perangkat secara real-time.
    </td>
    <td width="33%" valign="top">
      <h4>Payment Integration</h4>
      Midtrans dan Duitku untuk transaksi online di Indonesia.
